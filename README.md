# 🌐 Portafolio Personal - ABNER ABEL GOMEZ MENDOZA

Este es mi portafolio web personal desarrollado con **Angular**, donde muestro quién soy, mis proyectos, mis habilidades y mis formas de contacto. Es una aplicación de una sola página (SPA) totalmente **responsive**, moderna y con animaciones llamativas.

## 📌 Descripción

Bueno este proyecto fue creado con el objetivo de presentar mi perfil profesional de manera atractiva y accesible, ideal para **reclutadores**, **clientes** o **colaboradores**. La página cuenta con:

- ✅ Diseño responsive (se adapta a celulares, tablets y computadoras).
- 🎯 Navegación fluida entre secciones.
- ✨ Animaciones al hacer scroll (usando AOS).
- 💬 Formulario de contacto funcional (usando [EmailJS](https://www.emailjs.com), sin base de datos).
- 📄 Botón para descargar mi CV.
- 🔗 Enlaces directos a mis redes sociales.
- 🧠 Texto animado tipo máquina de escribir mostrando tecnologías que manejo.
- 📱 Botón flotante de WhatsApp.
- 🧰 Secciones ordenadas y profesionales.

## 🖼️ Secciones del sitio

1. **Inicio**
   - Header con los links de todas las secciones que estan en la pagina.
   - Imagen principal y texto de quien soy y que hago.
   - Texto con efecto de máquina de escribir que cambia dinámicamente.

3. **Sobre mí**  
   - Descripción personal y estudiante profesional.
   - Tecnologías que manejo y herramientas que uso.
   - Mi pasa tiempos..
   - tecnologia que uso y mis valores.
4. **Proyectos**
   -Falta modificar algunas cosas que lo hare con el paso del tiempo para poner mis proyectos con imagenes o links..
   - Tarjetas, descripciones y links a proyectos destacados como tambien mis proyectos futuros (GitHub o deploys).

6. **Contacto**  
   - Formulario funcional con validación básica.
   - Envío de mensajes directo a mi correo con EmailJS.
   - Íconos sociales (Facebook, LinkedIn, GitHub, Instagram, Gmail).
   - Botón flotante de WhatsApp.

## 🛠️ Tecnologías utilizadas

- **Angular**
- **Bootstrap 5**
- **TypeScript**
- **HTML5 & CSS3**
- **AOS (Animate On Scroll)**
- **EmailJS**
- **Iconos de Font Awesome / Bootstrap Icons**
